match /teamCycles/{cycleId} {
  allow read: if isAdmin();
  allow create: if isAdmin()
    && request.resource.data.keys().hasOnly([
      'schemaVersion', 'startDate', 'endDateExclusive', 'members', 'createdBy', 'createdAt'
    ])
    && request.resource.data.schemaVersion == 1
    && request.resource.data.startDate is string
    && request.resource.data.endDateExclusive is string
    && request.resource.data.members is list
    && request.resource.data.members.size() >= 2
    && request.resource.data.members.size() <= 200
    && request.resource.data.createdBy == request.auth.uid
    && request.resource.data.createdAt == request.time;
  allow update, delete: if false;
}

This is an integration fragment, not a replacement ruleset. Client validation
checks dates/56-day range, roles, unique names and teams. The rule above does not
validate every nested member or enforce non-overlapping cycles. Client validation
is not a server integrity guarantee. Before enabling storage, test unauthenticated
denial, non-admin denial, admin create/read, update/delete denial, catchall exclusion,
